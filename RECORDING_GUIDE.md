# 🎥 Website Preview Recording Guide

## 🚀 Quick Steps to Record & Share on WhatsApp

### Option 1: Windows Built-in Recorder (EASIEST)

1. **Start the website** at `http://localhost:3000`
2. **Open Screen Recorder**:
   - Press `Win + G` (Opens Xbox Game Bar)
   - Or press `Win + Alt + R` to start recording directly

3. **Record these sections** (2-3 minutes total):
   - ✅ Homepage hero with title & buttons
   - ✅ Click "GET QUOTE" to show lead form
   - ✅ Scroll to partner logos section
   - ✅ Scroll to Interactive Map section
   - ✅ Click on 3-4 cities to show hamper images:
     - Jaipur (Royal Ghewar hamper)
     - Mumbai (Kesar Peda)
     - Pune (Bakarwadi special)
     - Bengaluru (Mysore Pak)
   - ✅ Click "Configure Hamper" button
   - ✅ Show personalization section briefly
   - ✅ Fill and submit a test lead

4. **Stop Recording**:
   - Press `Win + Alt + R` again or click stop in Game Bar

5. **Find your video**:
   - Videos save to: `C:\Users\91942\Videos\Captures\`
   - File will be named something like: `xbox_game_bar_recording_2026-06-23_...mp4`

6. **Share on WhatsApp**:
   - Open WhatsApp Web or app
   - Create a new chat
   - Click attachment/paperclip icon
   - Select the MP4 video file
   - Send!

---

### Option 2: Using OBS (Better Quality)

If you have OBS installed:
1. Open OBS
2. Add Browser source pointing to `http://localhost:3000`
3. Click "Start Recording"
4. Follow the same walkthrough as above
5. Stop recording and export as MP4

---

### Option 3: Browser Extension

Install a browser recording extension like:
- Awesome Screenshot
- Screencastify
- Movavi Screen Recorder

- **Size**: Usually under 100MB (WhatsApp compresses)
- **Quality**: Windows recorder captures at 1080p60fps - perfect quality
